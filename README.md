# Remainy

Remainy is a small native macOS utility that keeps your remaining Codex usage close at hand—in Control Center or the menu bar.

## Download

Download the latest signed and Apple-notarized installer from [kaanyagci.com/remainy](https://kaanyagci.com/remainy/) or the [GitHub release](https://github.com/Makepad-fr/remainy/releases/latest).

## Requirements

- Apple Silicon Mac
- macOS 13 or later
- macOS 26 or later for the Control Center control
- A ChatGPT account with Codex access

## Install

1. Download the DMG.
2. Open it and drag Remainy into Applications.
3. Open Remainy and sign in with ChatGPT.
4. On macOS 26 or later, add Remainy from Control Center's Edit Controls view.

Remainy is distributed with a Developer ID signature and Apple notarization.
